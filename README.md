# CodeX Router

[![PHP Version](https://img.shields.io/badge/PHP-8.4%2B-777BB4?logo=php&logoColor=white)](https://www.php.net/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Strict Types](https://img.shields.io/badge/strict_types-enabled-4285F4.svg)](https://www.php.net/manual/en/language.types.declarations.php)

**CodeX Router** — современный высокопроизводительный маршрутизатор для PHP, построенный на основе префиксного дерева (Trie), поддерживающий группы маршрутов, middleware, именованные маршруты, генерацию URL, необязательные параметры, catch-all-сегменты и диспетчеризацию запросов.

Маршрутизатор не зависит от конкретного фреймворка и может использоваться как в небольших приложениях, так и в составе крупных архитектурных решений.

---

## Особенности

- Маршрутизация на основе префиксного дерева.
- Поддержка статических, динамических, необязательных и catch-all-параметров.
- Типизированные псевдонимы параметров: `int`, `float`, `slug`, `uuid`, `catchall`.
- Автоматическое приведение типов параметров маршрута.
- Группы маршрутов с префиксами, middleware и префиксами имён.
- Именованные маршруты и генерация URL.
- Поддержка query-параметров и фрагментов при генерации URL.
- Автоматическая поддержка HTTP-метода `HEAD` при наличии `GET`.
- Возврат списка разрешённых методов для ответа `405 Method Not Allowed`.
- Нормализация middleware через отдельный слой `MiddlewareDefinition`.
- Встроенный диспетчер запросов и middleware-конвейер.
- Возможность интеграции контейнера зависимостей.
- Строгая типизация и использование современных возможностей PHP 8.4.

---

## Требования

- **PHP 8.4 или выше**.
- Расширения:
  - `mbstring`;
  - `json`;
  - `pcre`.

> **Важно**: в коде используются property hooks, readonly-классы, перечисления и другие возможности современных версий PHP.
